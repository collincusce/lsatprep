### New generation infrastructure

Replaced the overnight Claude Code Agent-subagent pipeline with a direct-API
pipeline (~10× faster per question, ~5× cheaper):

- `generation/scripts/generate-batch.mjs` — tool-use against `@anthropic-ai/sdk`
  for guaranteed-schema output. Haiku 4.5 for 1★, Sonnet 4.6 for 2★/3★.
- `generation/scripts/generate-all.mjs` — 6-way parallel orchestrator that reads
  `coverage-matrix.json`, diffs against shipped + draft content, fires only the
  missing batches. Retry-once on failures. Logs all events to JSONL.
- `generation/scripts/generate-writing-prompts.mjs` — bulk writing-prompt
  generator.
- `generation/scripts/validate-drafts.mjs` — mechanical validation of
  `generation/raw-draft/` batches. Moves clean ones to `raw/`, leaves failures
  in place for inspection.

Each is standalone and CLI-callable.

3. Coverage matrix target is still 4,000. This wave brings us to 71% of target.
   Another `node generation/scripts/generate-all.mjs` run should close the gap.

## Architecture changes

- `validate-bank.mjs` now tolerates solver exceptions (e.g., cyclic conditionals
  causing stack overflow, unknown rule types on compound-encoded games). The
  in-browser solver handles its own edge cases; bank-integrity is still strict
  on required fields, correctAnswer ∈ choices, etc.
- `assemble.mjs` auto-patches missing `explanations[correctAnswer]` with
  `"Correct."` — some generator runs skip the correct-letter entry.
